Overview

什么是 ZEN GENE Translator？

ZEN GENE Translator 是一款运行在 Windows 后台的 AI 写作助手。无论你在哪个应用里打字，一个快捷键即可让 AI 帮你翻译或润色当前输入框中的文字，结果直接替换原文，全程无需切换窗口。

⚡
全局触发
在任意输入框按下热键或输入后缀，即刻启动 AI 处理。
🌐
双向语言
自动识别中英文，翻译或润色，无需手动切换模式。
✦
场景感知
根据当前窗口自动选择日常、随意或商务风格。
📋
原地替换
确认后直接替换输入框内容，剪贴板自动还原。
🤖
多 AI 服务商
支持 Anthropic、OpenAI、Gemini、DeepSeek、Groq、Ollama 等，一个入口接入所有模型。
🔒
本地配置
所有设置保存在本地，API Key 仅存于你的电脑。
Trigger

两种触发方式

根据你的使用习惯选择，两种方式可以同时启用。

1

热键触发  Ctrl + Shift + Space

在任意输入框内按下热键，ZEN GENE Translator 自动读取当前输入框的全部内容（或已选中的部分），发送给 AI 处理。热键组合可在设置中自定义。

2

后缀触发  ··（默认，可自定义）

在文字末尾连续输入两个触发字符（如 ··），自动检测并启动处理，后缀字符会从最终结果中自动删除。适合右手持鼠标时的左手操作。后缀字符可在设置中修改为任意两字符组合。

提示：如果你只选中了部分文字再触发，AI 只会处理选中的内容，其余文字保持不变。
Workflow

两种工作流程

可按需选择带弹窗的标准流程，或完全无感的静默替换模式。

💬 标准弹窗流程
触发后弹窗出现，AI 实时流式输出结果。查看满意后按 Enter 替换，或双击结果文字直接替换。可切换场景重新生成，或按 Esc 取消。
👻 静默替换模式
在设置中开启静默替换后，触发即处理，完成后文字直接替换，全程无任何弹窗。出错时仅通过系统托盘提示。适合熟悉工具的用户。
1

触发 → 弹窗出现（标准模式）

弹窗在光标附近出现，顶部显示原文，底部开始流式输出 AI 结果，动态指示符 · ·· ··· 表示正在生成。

2

查看结果 → 切换场景（可选）

弹窗顶部有 日常 / 随意 / 商务 三个场景按钮，切换后 AI 立即以新风格重新生成。场景切换会自动保存为下次默认。右下角 ↺ 可重试当前场景。

3

确认 → 文字替换

按 Enter 或双击结果文字，AI 结果直接替换回原输入框；按 Esc 或点击 取消 放弃，剪贴板自动还原。

Getting Started

快速上手

1

运行 ZenGene.exe

双击 exe 文件，程序自动运行到系统托盘（任务栏右下角出现圆弧图标）。左键单击图标可随时打开设置。

2

选择服务商并填写 API Key

首次运行自动弹出设置窗口。选择你使用的 AI 服务商，填入对应的 API Key 并保存。默认使用 Anthropic Claude，Key 在 console.anthropic.com 申请。

3

在任意输入框测试

打开记事本或任意聊天工具，输入一段文字，按 Ctrl+Shift+Space，观察弹窗出现并开始输出结果。

4

按 Enter 或双击替换

对结果满意后按 Enter 或直接双击结果文字，文字自动替换回输入框。熟悉后可开启静默替换，彻底省略这一步。
