怎么用

整个过程只有一个动作，其余都自动完成。

  1. 照常打字

    在微信、Outlook、Slack、浏览器……任何输入框里写中文草稿，或者写一段不太地道的英文。

  2. 按快捷键

    Ctrl Shift Space，或在末尾打出后缀字符（默认 ··）。选中一部分文字再按，就只处理选中的部分。

  3. 原地替换

    几秒内，输入框里的文字被换成地道英文。屏幕边缘出现一个小胶囊告诉你完成了。

  4. 不满意就撤销

    替换后 2.5 秒内再按一次快捷键，恢复原文。

它会替你判断

你不需要选模式、选语气。

翻译还是润色

出现中文就翻译成英文；全是英文就润色成地道表达。中英混写也会整段处理。

用什么语气

按你正在用的应用自动选：Outlook 用「商务」，微信用「随意」，其余用「日常」。可在托盘菜单里改。

写出意图

不逐字直译。粗糙的草稿会被整理成你真正想表达的意思，不会冒出 AI 腔和中式英语。

英文风格

美式、英式或新加坡式拼写与用词，在设置主页一键切换。

越用越懂你

这些都在 设置 → 高级 → 个性化，全部存在本机。

快速上手

免安装，一分钟就能用。

  1. 运行 ZenGeneInk.exe

    托盘出现 ZenGene 标志（一道圆弧加一个青色圆点）即已启动。

  2. 粘贴 API Key

    设置会自动打开。没有 Key？到 Cerebras 免费申请，每天有免费额度。以 csk-、gsk_、sk-ant-、sk-or-、AIza 开头的 Key 会自动选好对应服务商。

  3. 试一下

    随便找个输入框写句中文，按 Ctrl Shift Space。

快捷键

Ctrl Shift Space翻译 / 润色当前输入框（可自定义）
替换后 2.5 秒内再按一次撤销，恢复原文
末尾打 ··后缀触发（可自定义或关闭）
弹窗里 Enter / Esc替换 / 取消（仅在关闭静默替换时出现弹窗）

隐私

API Key用 Windows 系统加密（DPAPI）保存在本机
翻译历史可关闭；开启时逐条加密保存在本机，可导出或一键清空
发送给 AI 的内容只有你要处理的文字，以及开启上下文感知时的可见对话
诊断日志只记录耗时、成功与否等统计，不记录任何文字内容

系统要求

操作系统Windows 10 / 11（64 位）
网络能访问所选服务商的 API（Ollama 本地模式除外）
安装免安装，单个 exe；不需要管理员权限
换电脑复制 ZenGeneInk.exe 即可，首次运行重新填 Key
