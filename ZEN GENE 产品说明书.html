Overview

什么是 ZEN GENE？

ZEN GENE 是一款运行在 Windows 后台的 AI 写作助手。无论你在哪个应用里打字，一个快捷键即可让 AI 帮你翻译或润色当前输入框中的文字，结果直接替换原文，全程无需切换窗口。

⚡

🌐

自动识别中英文，翻译或润色，无需手动切换模式。
✦

Trigger

两种触发方式

根据你的使用习惯选择，两种方式可以同时启用。

1

热键触发  Ctrl + Shift + Space

在任意输入框内按下热键，ZEN GENE 自动读取当前输入框的全部内容（或已选中的部分），发送给 AI 处理。热键组合可在设置中自定义。

2

后缀触发  ·· （默认，可自定义）

在文字末尾连续输入两个触发字符（如 ··），自动检测并启动处理，后缀字符会从最终结果中自动删除。适合右手持鼠标时的左手操作。后缀字符可在设置中修改为任意两字符组合。

提示：如果你只选中了部分文字再触发，AI 只会处理选中的内容，其余文字保持不变。
Workflow

标准弹窗流程

触发后弹出翻译窗口，AI 实时流式输出结果，由你决定是否采用。

1

触发 → 弹窗出现

弹窗在光标附近出现，顶部显示原文，底部开始流式输出 AI 结果，动态指示符 · ·· ··· 表示正在生成。

2

查看结果 → 切换场景（可选）

弹窗顶部有 日常 / 随意 / 商务 三个场景按钮，切换后 AI 立即以新风格重新生成。右下角 ↺ 可重试当前场景。

3

确认 → 文字替换

按 Enter 或点击 确认 按钮，AI 结果直接替换回原输入框；按 Esc 或点击 取消 放弃，剪贴板自动还原。

智能语言识别

ZEN GENE 自动判断输入内容是需要翻译还是润色，无需手动选择模式。

🔄 翻译模式
当输入内容为中文时，翻译为英文；
当输入内容为英文时，翻译为中文。

自动检测
✨ 润色模式

自动检测

Getting Started

快速上手

1

运行 ZenGene.exe

双击 exe 文件，程序自动运行到系统托盘（任务栏右下角出现圆弧图标）。

2

填写 API Key

首次运行自动弹出设置窗口。前往 console.anthropic.com 获取 API Key，填入后保存即可。

3

在任意输入框测试

打开记事本或任意聊天工具，输入一段文字，按 Ctrl+Shift+Space，观察弹窗出现并开始输出结果。

4

按 Enter 替换

对结果满意后按 Enter，文字自动替换回输入框，完成。
